# Privacy

SetBrowser is a local macOS app and command-line tool.

It does not collect, store, transmit, or sell personal information. It does
not include telemetry or analytics.

SetBrowser does not read or transmit browsing history, opened URLs, account
information, cookies, credentials, or other browser data. It only discovers
installed browser applications locally and asks macOS to change the default
application for web links.

Any macOS confirmation dialog shown while changing the default browser is
provided by macOS.
