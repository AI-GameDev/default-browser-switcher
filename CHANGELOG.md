## 0.1.0 - 2026-05-28

Initial release.

- Add native SwiftUI macOS app for changing the default browser.
- Add `setbrowser` CLI.
- Discover compatible browsers from `/Applications` and `~/Applications`.
- Verify default browser changes by `http` and `https` bundle identifiers.
- Add settings for failure-only alerts and quitting after successful changes.
- Add keyboard navigation for browser selection.
- Add dark-theme app icon.
